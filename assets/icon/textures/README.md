# Rubber normal map

Generated with the built-in imagegen tool at the user's request. This is a normal
texture only; the icon itself is modeled and rendered in Blender.

`rubber_normal.png` is loaded as Non-Color data, mapped through planar UVs at 2.2×
scale, and connected through a tangent-space Normal Map node at strength 0.085.
The same microstructure is used on both rubber faces. The image is packed into
`../tabletennis_icon.blend`; the external file lets the scene-building script rebuild it.
